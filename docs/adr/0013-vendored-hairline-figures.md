# Vendored Hairline figures

`components/examples/hairline/kernel.js` is Hairline's engine, vendored byte-for-byte from `@lucasmarkes/hairline` (MIT) with a sha256 marker. It's excluded from ESLint and from the comment ban, so it can be diffed against upstream and re-vendored, and its license header and index stay intact. `pour.js` is a figure generated with the external `hairline-create` skill, whose page and look sheet live outside this repo. Edit it there and copy it back, keeping `import HL from "./kernel"` and the `pour` export. `espresso-machine.tsx` mounts that export and drives it with `pourTo(level, pouring)`. The figure leaves wide margins for its standalone page, so the `Cup` mounts it with a cropped viewBox (`CUP_BOX`). Re-measure the crop if the drawing changes.
