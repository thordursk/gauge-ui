# Site metadata and social images

- **`/og` is a screenshot stage.** `app/og/page.tsx` restages the hero at fixed sizes: `?variant=og` (1200×630, the default), `?variant=header` (the README banner) and `?theme=dark`. It exists only for an external headless-browser script that produces `app/opengraph-image.png` and the README header. Nothing links to it, and it's `noindex` and disallowed in `app/robots.ts`. Deleting it breaks regenerating the images.
- **The studio re-declares its OG image.** Next.js merges metadata shallowly, per top-level key. Defining `openGraph` in `app/studio/page.tsx` therefore replaces the root's, including the image the `opengraph-image.png` convention injects. The page re-declares `/opengraph-image.png` (2400×1260), and its size and alt text must be kept in step with the file.
- **Star count revalidates hourly.** `getRepoStars` (`lib/github.ts`) calls the unauthenticated GitHub API with `next: { revalidate: 3600 }`. The landing page stays static and well inside the 60-per-hour anonymous limit, at the cost of a count up to an hour stale. On failure it returns `null` and the button shows only the icon.
- **Fonts.** Geist is the site's typeface. `app/layout.tsx` still loads Inter (`--font-sans`) and Nunito (`--font-rounded`) on every page, because gauge specs and the scenes offer "sans" and "rounded" options that resolve to those variables. That costs two extra font downloads.
